How to use使用方式

  1. Download mmvp.exe from GitHub Releases, put it in a writable folder and run it (no installer).
  2. Close the game, open mmvp, check the game folder and press “Apply JP voices”. The program downloads the voices it needs from here.
  3. After a game update or when new JP voices are out, the program asks you to re-apply. It also offers its own updates.
  1. 從 GitHub Releases 下載 mmvp.exe，放在可寫入的資料夾直接執行（免安裝）。
  2. 關閉遊戲，開啟 mmvp，確認遊戲目錄後按「套用日文語音」。程式會自動從這裡下載需要的語音。
  3. 遊戲更新或有新的日文語音時，程式會提示重新套用；程式本身也會自動提示更新。
