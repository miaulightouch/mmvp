瑪奇 Mobile 日文語音

把台版用戶端的 NPC 與劇情語音換成日版配音。只替換語音，原始遊戲檔案不會被修改，隨時可以還原。

使用方式

  1. 從 GitHub Releases 下載 *-setup.exe 並安裝（不需要系統管理員權限）。
  2. 關閉遊戲，開啟「MabiMobile JP Voice」，確認遊戲目錄後按「套用日文語音」。程式會自動從這裡下載需要的語音。
  3. 遊戲更新或有新的日文語音時，程式會提示重新套用；程式本身也會自動提示更新。

非官方工具，與 NEXON、devCAT 無關。
